🔄 Enrollment Logic

Scenario 1: New Premium Member

  1. Premium member joins SKOOL community
  2. Skooly webhook fires → /api/webhooks/skooly
  3. Webhook calls enrollPremiumMember(leadId, joinDate, false)
  4. 6 Premium emails scheduled
  5. Day 0 Welcome Email sent (separate, existing automation)

Scenario 2: Standard-to-Premium Upgrade

  1. Standard member upgrades to Premium in SKOOL
  2. Skooly webhook fires → detects isPremium && wasStandard
  3. Webhook calls enrollPremiumMember(leadId, upgradeDate, true)
  4. Function cancels all pending Standard emails
  5. 6 Premium emails scheduled
  6. Day 0 Welcome Email NOT resent (member already welcomed)
