Error handling confirmed in lib/webinarjam-registration.ts:

try {
  // Call WebinarJam API
  const response = await fetch(...)
  
  if (!response.ok) {
    throw new Error(`WebinarJam API error: ${response.status}`);
  }
  
  // Update registration with success
  await prisma.webinarRegistration.update({
    where: { id: registration.id },
    data: {
      registrationStatus: 'registered',
      webinarJamRegistrantId: data.registrant_id,
      webinarJamLiveRoomUrl: data.live_room_url,
      webinarJamReplayRoomUrl: data.replay_room_url
    }
  });
  
} catch (error) {
  // Log error, update registration with failure state
  console.error('WebinarJam registration failed:', error);
  
  await prisma.webinarRegistration.update({
    where: { id: registration.id },
    data: {
      registrationStatus: 'failed',
      lastError: String(error)
    }
  });
  
  throw error; // Propagate to caller
}

Architecture: Failures are logged, registration record updated with error state, and error propagated to prevent false success message.
